# PN-LMCGS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox ("- [ ]") syntax for tracking.

**Goal:** Add opt-in Positive-Negative Landmark Monte Carlo Graph Search with environment-agnostic binary safety costs while preserving the existing L3P path.

**Architecture:** Add a focused l3p/pn_lmcgs package for safety learning, landmark memories, macro replay/model/calibration, MCGS, and the trainer adapter. Extend the existing environment, replay, agent, and trainer only at their ownership boundaries. Keep a separate legacy collection/planning branch whenever pn_lmcgs_enabled is false.

**Tech Stack:** Python 3, NumPy, PyTorch, pytest

- [ ] **Step 4: Implement risk, PUCT, chance transitions, and backup**

Initialize alpha/beta exactly from model risk. Keep a model-feasible edge searchable while its rollouts have accumulated no positive safety return, then switch search feasibility to the conservative posterior upper bound. Root selection always uses the upper bound. Sample outcomes and drift IDs from the seeded NumPy generator. Apply terminal penalties and back up the same task/safety return across selected edges.

```python
def feasibility_risk(self) -> float:
    return self.prediction.p_violation if self.visits == 0 else self.upper_risk

def search_risk(self) -> float:
    prior_alpha = 1.0 + self.pseudocount * self.prediction.p_violation
    return self.prediction.p_violation if self.alpha <= prior_alpha else self.upper_risk

def update(self, reward_return: float, safety_return: float) -> None:
    self.visits += 1
    self.reward_sum += reward_return
    self.alpha += safety_return
    self.beta += 1.0 - safety_return
```
